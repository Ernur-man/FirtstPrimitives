\# Assignment 1 — OpenGL



\*\*Author:\*\* Yernur  

\*\*OS:\*\* Windows 10/11  

\*\*Libraries:\*\* GLFW, OpenGL 3.3+

OpenGL assignment with 2 tasks.

Task 2 Part 2 — creative scene: red house, yellow background, blue sidewalk.



\## How to build and run



```bash

make

```
